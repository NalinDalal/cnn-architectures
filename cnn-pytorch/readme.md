# PyTorch CNN Implementation

This folder contains a full PyTorch implementation of a simple CNN for MNIST/CIFAR-10, mirroring the NumPy structure.

## Structure
- `init.py`: Main script and model definition
- `layers/`: Custom layer classes (if needed)
- `utilities/`: Helper functions (data loading, training, plotting)
- `data/`: Dataset files
- `outputs/`: Model outputs, logs
- `public/`: Diagrams, images

## Usage
1. Place dataset files in `data/`.
2. Run `init.py` to train and save the model.
3. Outputs and logs will be saved in `outputs/`.
