## 2 - Naive Face Verification
Face verification involves comparing two images to determine if they belong to the same person. A naive approach is to compare pixel values directly, but this is not robust to variations in lighting, orientation, and other factors. Instead, we use encodings generated by a neural network for more accurate comparisons.

## 3 - Encoding Face Images into a 128-Dimensional Vector

### 3.1 - Using a ConvNet to Compute Encodings
The FaceNet model encodes face images into 128-dimensional vectors. The model uses a ConvNet architecture based on the Inception model. The input images are resized to 160x160 RGB images, and the output is a 128-dimensional encoding.

### 3.2 - The Triplet Loss
The triplet loss function ensures that encodings of the same person are close together, while encodings of different persons are far apart. The loss function is defined as:

$$
L = \sum_{i=1}^m \left[ \|f(A^{(i)}) - f(P^{(i)})\|^2_2 - \|f(A^{(i)}) - f(N^{(i)})\|^2_2 + \alpha \right]_+
$$

Where:
- $A$ is the anchor image.
- $P$ is a positive image (same person as $A$).
- $N$ is a negative image (different person from $A$).
- $\alpha$ is a margin hyperparameter.

## 4 - Loading the Pre-trained Model
The FaceNet model is pre-trained using the triplet loss function. The model is loaded from a JSON file and its weights are loaded from an H5 file. The model outputs a 128-dimensional encoding for each input image.

## 5 - Applying the Model

### 5.1 - Face Verification
The face verification system checks if a given image matches the identity of a person in the database. The L2 distance between the encoding of the input image and the stored encoding is computed. If the distance is below a threshold (e.g., 0.7), the person is verified.

### 5.2 - Face Recognition
The face recognition system identifies a person from a database of authorized individuals. The system computes the encoding of the input image and finds the closest match in the database using the L2 distance.
